# AulaLengua · 5.º Primaria

Aplicación docente **standalone** para Lengua Castellana y Literatura de 5.º de Educación Primaria (Castilla-La Mancha).

## Cómo usarla (la forma más fácil)

**Abre este enlace directamente en tu navegador:**

### ➡️ https://esnuqui-commits.github.io/AulaLengua-5Primaria/AulaLengua_Standalone.html

También puedes descargar el archivo `AulaLengua_Standalone.html` y abrirlo con doble clic.

No necesita instalación ni servidor.

## Características

- Panel de control con cobertura mínima (4 ejercicios por sección)
- 5 secciones + 20 ejercicios de ejemplo
- Generador de ejercicios adicionales
- Criterios oficiales (Decreto 81/2022 + RD 157/2022)
- Constructor de exámenes + matriz de cobertura curricular
- Vista previa de examen maquetada
- Guardado de exámenes en el navegador (localStorage)

## Sobre el visor SM

El visor de SM es accesible visualmente pero está protegido (formato XOD). Esta aplicación usa estructura de ejemplo + generación de ejercicios basados en el currículo oficial.
